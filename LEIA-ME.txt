GASTOS GIOVANNA - como funciona e o que cuidar
===============================================

O app esta no ar em https://gastos-giovanna.web.app
Abre em qualquer celular pelo navegador. Para virar icone na
tela do iPhone: Safari -> botao de compartilhar -> "Adicionar a
Tela de Inicio".


1. PUBLICAR
-----------
E automatico. Todo push na branch main dispara o GitHub Actions
(.github/workflows/pages.yml), que copia os 6 arquivos do app
(index.html, config.js, sw.js, manifest.json, icone-192.png,
icone-512.png) para o site gastos-giovanna no Firebase Hosting.

Toda vez que alterar index.html ou sw.js, troque a linha
   const CACHE = 'gastos-v4';
para 'gastos-v5', 'gastos-v6' e assim por diante. E isso que
descarta o cache velho nos aparelhos que ja instalaram.


2. NUVEM (ja configurada)
-------------------------
Projeto Firebase: fazenda-e3652, plano Spark (sem custos).
O config.js leva so o projectId. O app nao usa Authentication,
Storage nem Analytics, e o Firestore aceita acesso anonimo, entao
as outras chaves do firebaseConfig nao fazem falta.

ATENCAO: o banco Firestore e COMPARTILHADO com o sistema da
fazenda. Os dados vivem separados (/farms para a fazenda,
/carteiras para os gastos), mas as regras de seguranca sao um
arquivo unico para os dois. Ver item 4.


3. COMO FUNCIONA O ACESSO (leia isto)
--------------------------------------
Nao existe login. O codigo da carteira e a senha, e e tudo o que
existe entre os gastos e a internet. Por isso:

- Use SEMPRE o botao "Gerar codigo". Ele cria 12 caracteres
  aleatorios (cerca de 10^18 combinacoes), o que torna inviavel
  alguem acertar por tentativa.
- Nunca use nome, apelido, data de nascimento, placa, CPF.
  Um codigo adivinhavel abre a carteira para quem adivinhar.
- Para o casal ver os mesmos lancamentos, os dois aparelhos usam
  O MESMO codigo. Ajustes -> "Copiar link de acesso" e abra esse
  link no outro aparelho. O link contem o codigo, entao mande so
  para quem vai usar (nao em grupo, nao em rede social).
- Quem tiver o codigo ve e edita todos os lancamentos. Nao ha
  como revogar um codigo ja compartilhado a nao ser mudando de
  codigo (Ajustes -> Trocar codigo) e relancando os gastos.


4. REGRAS DO FIRESTORE
----------------------
O arquivo firestore.rules deste repositorio e a copia fiel do que
esta publicado. Ele cobre OS DOIS APPS. Publicar so a metade dos
gastos derruba o acesso da fazenda ao proprio banco, e vice-versa.

Elas sao publicadas A MAO: Firebase Console -> fazenda-e3652 ->
Firestore Database -> aba Regras -> colar -> Publicar. O deploy
automatico nao mexe nisso, porque a conta de servico usada pelo
GitHub Actions (github-actions-deploy@fazenda-e3652) so tem
permissao de Hosting - nao enxerga Firestore nem IAM.

Se um dia as regras da fazenda mudarem no console, copie a
mudanca para firestore.rules tambem, para o arquivo nao ficar
mentindo sobre o que esta no ar.

O que as regras dos gastos fazem: exigem codigo de 10 a 24
caracteres, proibem LISTAR a colecao de carteiras (sem isso,
qualquer um baixaria a lista de todos os codigos existentes) e
limitam o que pode ser gravado, para o banco nao virar deposito
de lixo alheio.


5. O QUE ESPERAR NO DIA A DIA
------------------------------
- Sem internet o app continua lancando. O indicador no topo mostra
  "Offline" e o Firestore envia tudo sozinho quando a rede voltar.
- O X de cada lancamento pede confirmacao: o primeiro toque vira
  "Apagar?", o segundo apaga. A confirmacao expira em 4 segundos.
- Nao da para remover uma categoria que ainda tem lancamentos.
  Troque a categoria deles antes (toque no lancamento para editar).
- "Baixar CSV de todos os meses" exporta o historico inteiro,
  separado por ponto e virgula, ja com BOM: abre direto no Excel.
- A cota gratuita do Firebase (50 mil leituras/dia) e muito maior
  do que um uso domestico consome.


6. LIMITES CONHECIDOS
----------------------
- So registra saida de dinheiro. Nao ha receitas, saldo nem
  parcelamento de compras no credito.
- Nao ha separacao entre "gasto pessoal" e "gasto da casa" alem
  da categoria. Tudo cai na mesma carteira.
- Editar categorias nos dois aparelhos ao mesmo tempo faz a
  ultima gravacao vencer. Irrelevante para duas pessoas.
- O codigo fica salvo no aparelho. Quem destravar o celular abre
  o app direto.
- O que foi lancado antes da nuvem existir ficou so no aparelho e
  nao sobe sozinho: aqueles lancamentos precisam ser redigitados.
